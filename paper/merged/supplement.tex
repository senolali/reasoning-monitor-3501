\paragraph{Evidence labels.}

\emph{prespecified secondary} when frozen but not primary,

seen, and \emph{post-hoc} otherwise. Frozen results are never relabelled;
sensitivity analyses appear beside rather than replace them.

\section{Study 1 (LIC-RQ-v2): additional details}

\subsection{Task audit and sample}
The public math subset contains 103 tasks and 585 shards. Before any model call,
an input audit excluded two groups of tasks:
\begin{itemize}
  \item 11 tasks whose normalized question exactly matched an input of our
    earlier, unrelated experiments;
  \item 8 tasks whose shard sequence appeared to alter the original problem, for
    example a lost comparison or ambiguous wording.
\end{itemize}
The two groups overlap in 2 tasks, which leaves 86 eligible tasks.

A deterministic, hash-based selection that does not use any model output then
drew 4 integration tasks and \nTasks{} science tasks. The integration stage
checked only transport, resume, parsing, scorers and plotting. Its effect
direction could not change the sample.

\subsection{Prompts}
\begin{description}
  \item[System prompt.] \emph{Solve incrementally using only information
    supplied in this conversation. Prior assistant replies may be wrong and are
    not authoritative facts.}
  \item[Primary instruction.] \emph{Give concise numbered reasoning steps using
    only the information available so far. End with exactly one final line:
    FINAL\_ANSWER: <number> when the numeric answer is determined, otherwise
    STATUS: NEED\_MORE\_INFORMATION.}
  \item[Rewordings ($L=2$).] Two frozen paraphrases of the instruction, which
    differ in wording but not in the response contract.
\end{description}

Both arms received a packed JSON transcript in a single user message:
\begin{itemize}
  \item the user shards only (fresh prefix), or
  \item the user shards interleaved with the model's earlier primary replies
    (dialogue history).
\end{itemize}

\subsection{Parsing and empty responses}
The strict final-line parser of the original protocol was too narrow. In the
technical integration stage it rejected many responses that did carry an
explicit marker. Before the science run, a semantic-contract parser was frozen.
It still requires the explicit marker but accepts numbering, units and minor
status variants. Raw responses and strict scores are retained.

Six Mistral-7B primaries were empty despite a successful API status. They were
kept as invalid, never retried, and represented in later history by the token
\texttt{[EMPTY\_PRIMARY\_RESPONSE]}.

\subsection{Per-model metric trajectories}
All six per-turn trajectories, their support counts and complete-case means are
included as vector figures in the reproducibility archive. Structurally
unobservable values are retained as gaps rather than coded as zero.

\subsection{Post-hoc stream replay}
Completed sessions were replayed as stream items, with the regime switching from
fresh prefix to dialogue history over the same 48 tasks. Two switch patterns were
used: sudden (LIC-S) and gradual (LIC-G).

\begin{itemize}
  \item Windows: $W\in\{10,20,30\}$.
  \item Detectors: CUSUM, Page--Hinkley, EWMA, DDM and ADWIN.
  \item Strategies: three detector-assignment strategies.
  \item Error control: thresholds calibrated on 2,000 permutation nulls, with

\end{itemize}

\section{Study 2 (CDR-Stream): additional details}

\subsection{Generator}
Each dialogue has 100 turns. Every user turn realizes one or more state events,
optionally adds distractor sentences, and asks one question from one of six
families: sum, difference, count-above-threshold, maximum, what-if and share.

Exact solvers keep the state and compute the gold answer. The generator checks
two things:
\begin{itemize}
  \item a solver round trip on every turn;
  \item that paraphrased questions re-derive the same answer.
\end{itemize}

Difficulty follows a 12-level ladder (Table~\ref{tab:ladder}) in which exactly
one axis changes per step. Levels 13--14 are contingency levels, used only under
the frozen ceiling rule.

\subsection{Difficulty calibration and model selection}
A single-turn calibration stage fitted the regime-to-level mapping for every
model and domain before any stream existed. Four rules were frozen:
\begin{itemize}
  \item fitting by isotonic regression;
  \item a one-sided Cochran--Armitage trend test with $p\le0.01$;
  \item adjacent regime gaps of at least 0.10 and an easy--hard gap of at least
    0.25;
  \item exclusion of a domain if any of these failed, and exclusion of a model if
    contract validity was below 0.90 or any response was truncated.
\end{itemize}

The calibration went through several frozen rounds:
\begin{itemize}
  \item The first ladder was too coarse.
  \item A one-axis-per-step ladder replaced it.
  \item A scheduling domain was replaced by the shallower milestone-chains domain.
\end{itemize}

Several candidate models were replaced, each before any stream result existed:
\begin{itemize}
  \item Mistral-7B sat at the accuracy floor and truncated responses.
  \item A frontier model's gateway truncated outputs in one domain.
  \item Gemma 4 31B reached the ceiling even at the contingency levels.
  \item Gemma 3 12B replaced it.
\end{itemize}

\paragraph{Repeat diversity of the Llama family.}
Consistency and stability require stochastic repeats. A technical pilot showed
that Llama-4 Scout produced near-identical repeated samples. Identical prompts
were therefore replayed against every Llama variant available
(Table~\ref{tab:kdiv}). Only Llama-3 70B met the frozen 0.80 diversity gate.

A context-capacity probe established that Llama-3 70B accepts the full 100-turn
packed history (37,139 gateway prompt tokens at turn 100) and recalls its oldest
message there.

\subsection{Recorded deviations for Llama-3 70B}
The investigator recorded two deviations for Llama-3 70B. Both were made after
the relevant gate result was seen, and both are disclosed here.

\begin{itemize}
  \item \textbf{Calibration rule overridden.} One of 1,440 calibration responses
    reached the 2,048-token ceiling. It was long reasoning in a domain that was
    excluded for this model on accuracy grounds. The frozen any-truncation rule
    was overridden for this model only. Mistral-7B, by contrast, had been
    excluded under the same rule with five truncations.
  \item \textbf{Pilot gate overridden.} The technical pilot had two truncated
    non-primary responses, both repetition loops. Its zero-truncation gate was
    overridden as well.
\end{itemize}

In place of the second gate, a truncation policy was frozen for all models
before the main run:
\begin{itemize}
  \item a truncated response is kept verbatim and scored as missing;
  \item a truncated primary enters later history as a placeholder;
  \item a sensitivity analysis rescores truncated cells as incorrect.
\end{itemize}

\subsection{Acquisition and staged analysis}
The main run was paused twice by the funding budget. At the second pause,
25,039 of 54,000 calls had been made. Because primaries are scheduled first, all
90 dialogue-history primary chains were complete at that point. The one
exception was a single Llama turn-100 primary.

The analysis protocol was frozen before any main-run metric was computed. Stage A
analyses every model--metric pair that had been fully acquired. Stage B
(consistency, robustness, stability and control for Llama-3 70B and Gemma 3 12B)
was committed, before any Stage A result was seen, to proceed regardless of the
Stage A results.

At Stage A, Llama-3 70B had two truncated primaries, and no other model had any.
The truncated-as-incorrect sensitivity analysis changed no result.

The frozen control-arm completion added 3,000 control calls for each of
Llama-3 70B and Gemma 3 12B. H-C1 used the per-dialogue mean
$CQ_{control}-CQ_{dialogue}$ over turns 1--100, a one-sided sign-flip test and
Holm correction over these two models. The mean gaps were
\cdrLlamaControlGap{} (95\% bootstrap CI [\cdrLlamaControlCiLo{},
\cdrLlamaControlCiHi{}], Holm $p=\cdrLlamaControlHolmP{}$) and
\cdrGemmaControlGap{} (95\% CI [\cdrGemmaControlCiLo{},
\cdrGemmaControlCiHi{}], Holm $p=\cdrGemmaControlHolmP{}$), respectively. Each
estimate contains 30 paired dialogues. The secondary turns 21--100 gaps were
\cdrLlamaControlLateGap{} and \cdrGemmaControlLateGap{}.

The per-turn control and dialogue trajectories for all three models are shown
in the main article and supplied as vector graphics in the archive.

\section{Detector power simulation}
The simulated streams have pre-change accuracy 0.80 and a drop $\delta$ at turn
34 or 51. Each turn aggregates $m$ independent dialogues.

\begin{itemize}
  \item Detectors and grids: the unchanged ones used in the analyses.
  \item Calibration: 2,000 nulls (oracle), or 200 random subsets of 36 or 12
    nulls.
  \item Drift streams: 300 per cell.
\end{itemize}

The main article reports the decision-relevant $W=20$ summary. The complete grid
of smallest detectable drops across windows, calibration sizes and change
points is retained in the archive.

\section{ADWIN implementation defect and audit}
\label{sec:adwin}
The historical ADWIN used the cut bound
$\epsilon=\sqrt{(2/m)\ln(2n/\delta)}$, without the variance term of
\citet{bifet2007learning}. For $n\le100$ values in $[0,1]$, this $\epsilon$ exceeds
every attainable difference in means. No ADWIN cell in any of our result tables
ever alarmed.

Every affected analysis was re-run with two substitutes:
\begin{itemize}
  \item a corrected ADWIN that uses the variance bound;
  \item CUSUM.
\end{itemize}
No recorded decision changed (Table~\ref{tab:adwreplay}).

The corrected ADWIN is faithful to the published bound but too conservative for
100-turn streams (Table~\ref{tab:adwv}). Its $(2/3m)\ln$ term does not shrink
with aggregation.
